# 网站阶段与独立新站分类

## 状态

已接受，2026-11-26，用户确认保留独立新站分类，阶段补齐平稳、下降，总表显示并支持筛选新站。

## 决策

阶段按待评估、验证、增长、平稳、下降、维护、暂停排列。平稳、下降描述管理者对当前经营表现的判断；维护描述当前经营策略，不与平稳合并。阶段仍由人工维护，不根据点击或收入自动改写。

新站继续使用既有的独立分类：默认按主域名注册日期是否在最近三个日历月内判断，允许手动标记新站、普通站或恢复自动判断。月末边界取目标月的最后一天，忽略非法日期及未来日期。新站可以同时处于增长、平稳或下降等任意阶段。

共享阶段定义供前端选项、类型、API 校验与默认排序使用；数据库 CHECK 约束同步更新。所有新增、编辑、批量设置、批次成员筛选和阶段分配入口使用完整阶段集合，备份恢复保留阶段与新站覆盖值。

总表在阶段下方以轻量文字显示新站；不增加列或彩色色块。新增新站分类筛选，`new=1` 为新站，`new=0` 为普通站，与阶段和其他条件组合，并在网址、筛选标签、清除条件及单站/多选分析复制中保持一致。

## 迁移边界

v1.30 在原网站表增加带新约束的临时阶段列，复制旧阶段，再替换旧列并恢复阶段索引。保留网站主键、原阶段、其他字段、外键、触发器和自增序列；不重建父表或重设已有网站阶段。先备份并演练，迁移数据库后发布应用。
