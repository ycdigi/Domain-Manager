# 平台图标与技术栈核对（2026-11-21）

服务商名称为空或仍为通用分类时，根据账号名称识别 SiteGround 和 Hostinger。已明确填写的其他服务商品牌优先；无法识别的虚拟主机继续显示通用图标。选项、选中状态和关联列表使用相同规则。

用户提供的 Dynadot CSV 共 122 个域名，系统匹配 120 个。匹配记录的注册商、注册日期、到期日期与现有值一致，链接也等价，无需重复写入。`goodskills.vip` 与 `maxdomachine.com` 不在当前系统，未擅自新增网站或域名。

程序检查当前 120 个网站的主域名，依据页面生成器、框架资源路径和运行节点识别，普通正文提及不作为依据。排除失败响应、站外跳转、挑战页及停放页面；主页面无特征时抽查同站内容页。首次网络失败后使用另一 HTTP 客户端补充获取，没有关闭 TLS 校验。

确认 106 个：Astro 46、Next.js 18、WordPress 42。19 个与旧记录不同，第二次获取重复确认后更新；未确认的 14 个保留原值，其中 8 个停放页、6 个连接超时。无法据此声称所有网站均已识别。

可重跑命令：`node scripts/audit-website-stacks.mjs input.json report.json`。输入为包含 id、domain、platform、platform_other 的网站数组，输出包含每次请求地址、状态及命中特征；脚本只生成报告，不自动更新线上。

完整生产备份、域名匹配记录、逐站证据、变更 SQL、原值恢复 SQL及生产复核保存在忽略目录 `backups/`，未上传源代码仓库。142 项 Node 测试、资源浏览器回归、构建、清理及监控类型检查通过。
