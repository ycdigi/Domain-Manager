# 网站归属关系需求访谈

记录日期：2026-11-06。状态：完整实施范围已确认，本地实现及验收通过；尚未发布或迁移线上数据库。

## 已确认

- 网站归属关系与技术栈、网站类型是独立维度。
- 网站归属关系为单选：未分类、自营网站、企业客户网站。
- 自营网站由管理者自己运营，包含推广及 Google AdSense 变现业务；企业客户网站由管理者为企业客户提供服务。
- 新增和编辑网站时均可设置网站归属关系。
- 新增网站默认选择自营网站。未分类仍作为可选项保留。
- 网站列表和详情都展示网站归属关系。
- 网站归属关系与技术栈可以同时筛选，结果必须同时满足两项条件。例如，自营网站 + WordPress。
- 现有网站统一归为自营网站，不根据技术栈、网站类型或 AdSense 状态推断归属。
- 网站列表支持直接切换网站归属关系。
- 侧边导航分为网站归属和技术栈两组；归属组包括全部归属、自营网站、企业客户网站、未分类。
- 初始筛选为全部归属 + 全部技术栈。
- 本次只增加归属分类，不增加企业名称、联系人或客户档案。
- 本次只支持逐个修改归属，不增加批量修改操作。
- 网站数量、到期、SEO、点击分布等网站级概览跟随网站归属和技术栈筛选，并明确展示当前统计范围。
- 账号累计收入、基础设施总量仍展示全局数据，并明确标注全局；不按网站归属或技术栈拆分账号收入。
- 技术栈导航数量受当前归属筛选约束；归属导航数量受当前技术栈筛选约束。
- 搜索词只影响网站列表，不影响导航数量和概览统计。
- 导出继续包含全部数据，按钮明确标为“导出全部”。
- 导入、导出和 AI 同步均支持网站归属关系。
- 旧导入文件或同步请求未提供归属时，已有网站保留原归属；新导入的网站默认自营网站。
- 新增始终默认自营网站，不随当前归属筛选改变默认值。
- 新增或修改保存后保留当前筛选。若该网站不符合当前筛选，列表按条件更新，并提示“已保存，该网站不在当前筛选范围内”。
- 刷新、从详情返回以及浏览器前进后退时恢复归属与技术栈选择。首次进入且没有保存条件时显示全部归属 + 全部技术栈。
- 桌面与手机遵循相同的归属分类和筛选规则。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 升级已有数据库 | 现有网站均归为自营网站，保留原技术栈和网站类型等信息。 |
| 新增网站 | 默认自营网站，可切换企业客户网站或未分类。 |
| 编辑、查看详情和列表 | 编辑可修改归属，详情和列表可查看归属，列表可直接切换归属。 |
| 企业客户网站 + WordPress | 仅列出同时满足两项条件的网站；网站类型仍独立保留。 |
| 切换任意一组筛选 | 另一组选择保留；导航数量按另一组条件计算。 |
| 输入搜索词 | 列表进一步缩小；导航数量和概览不随搜索词变化。 |
| 查看筛选后的概览 | 网站级指标只统计当前归属与技术栈范围，账号收入和基础设施总量明确标为全局。 |
| 当前筛选下新增或修改归属 | 筛选不变；保存后不匹配的网站不在列表中显示，并给出范围提示。 |
| 刷新、详情返回、浏览器前进后退 | 恢复两组筛选；桌面与手机规则一致。 |
| 在筛选状态下点击导出全部 | 导出全部数据，包含每个网站的归属关系。 |
| 使用含归属字段的备份导入 | 恢复网站归属，不丢失分类。 |
| 旧文件导入或 AI 同步未提供归属 | 已有网站保留原归属；新导入的网站默认自营网站。 |

## 范围外

- 企业客户名称、联系人及客户档案管理。
- 勾选网站后批量修改归属。
- 将账号收入自动按网站归属或技术栈拆分、均摊。
- 仅导出筛选结果。
