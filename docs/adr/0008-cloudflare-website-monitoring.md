# Cloudflare 原生巡检与站内告警

## 状态

已接受（2026-11-12）

## 决策

现有 Pages 负责管理界面和登录保护 API，独立 Worker 用 Cron 分批巡检，共用 D1。每站默认十二小时一次，首次失败五分钟后复查，连续两次失败记录事件。只提供站内提醒。暂停和停止经营的网站不自动巡检。网站监控判断与原有域名可用性分开：内容异常不能把可访问的页面直接记为离线。

此能力取代原有每六小时 GitHub Actions 的自动检查，保留旧状态接口兼容已有调用。检查使用 HTTPS、严格 2xx、有限跳转和静态文本规则；标题变化交由管理者复核，不把首个标题样本当成安全认证。租约防止并发重复检查，主域名或配置改变时拒绝旧结果。监控与 SEO 复查、收入或经营阶段决策相互独立。

## 原因

网站组合需要在不逐站访问的情况下发现访问故障、页面替换线索及监控自身停止运行。将巡检放在 Cloudflare 可以沿用现有部署和数据库，避免维护另一套服务器或通知服务。
