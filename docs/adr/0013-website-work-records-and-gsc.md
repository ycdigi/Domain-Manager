# 网站工作登记与 GSC 账号归属

## 状态

已接受，2026-11-21。沿用既有网站主体与规范数据模型，不改变旧操作记录。

## 决策

四类工作登记使用 `website_work_records`，按每次操作独立记载；`website_operations` 继续保存旧的按日记录。网站内请求编号唯一，保证重试幂等；撤销使用 `voided_at`，聚合只计算未作废记录。

GSC 账号使用 `gsc_accounts` 和 `website_gsc_accounts`，名称与非空邮箱分别唯一，每站至多关联一账号。关联表示管理归属，不表示 Google 授权或 GSC 开通状态，不存 Google 密码。账号名称及邮箱修改通过稳定编号影响所有关联网站。

普通备份明确包含三张新表。恢复的统计数量和历史时间来自原始记录，界面及 Excel 不另建汇总真值。恢复已存在的历史指标允许统计日期缺失，保持原数据；日常指标编辑继续要求日期。

## 取舍

分开历史记录避免把一次按天操作推断为某类具体工作。作废记录保留了请求身份，备份恢复后重试也不会重新计数。GSC 账号完全由管理者录入，初始不猜填账号。
