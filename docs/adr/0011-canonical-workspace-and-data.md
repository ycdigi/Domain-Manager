# 唯一工作区数据模型与任务分区

## 状态

已接受，2026-11-21。替代 ADR 0010 中长期保留旧字段映射和触发器的取舍；替代 ADR 0009 当前复盘依赖场景的部分。历史证据保留。

## 决策

网站总表采用固定列（2026-11-23 依 ADR 0010 补充扩为十三列）并显示全部生效条件，搜索排序进入网址。详情使用七个任务分区、独立读取及统一草稿保护。账号归属使用 website_accounts；托管及代码位置必须由实际资源表达。

运行接口和数据库只保留规范数量、网站电脑、美元及人民币账号收入、HTTP 监控。旧值先归档，再一次升级；不保留别名、同步触发器和旧格式导入。备份由唯一端点输出版本 1，明确排除凭据及缓存。

## 取舍

清理减少多套实现的遗漏风险，但旧客户端和旧文件必须先升级。发布需要维护窗口、完整备份、本地 D1 演练和配套版本恢复，不能依赖应用单独回滚。
