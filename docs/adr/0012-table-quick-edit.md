# 网站总表快捷编辑与 IP 列移除

## 状态

已接受，2026-11-21，用户明确要求。替代 ADR 0010、0011 中总表固定十二列的部分；其他数据与资源建模决策继续生效。本次整合保留后续加入的 AdSense 列，最终十二列；发布状态以发布记录为准。

## 决策

总表移除服务器 IP 列，保留其后的 AdSense 列，最终十二列；IP 仍属于托管资源，可在部署资料查看。移除列定义、单元格、排序值和原复制处理，旧 `sort=ip` 地址按默认顺序展示，不保留隐藏排序。

阶段、电脑、技术栈直接下拉选择。电脑与技术栈允许输入新名称；自定义技术栈仍按 `platform=其他` 与 `platform_other` 保存，电脑仍属于网站。选项沿用现有电脑配置。

技术栈使用图标下拉，完整名称可在悬停及选项中查看；数量列使用紧凑宽度，宽屏多余空间分配给网站名称列，保留移动端至少 44px 操作目标。

总页面数、计算器数量、文章数量和日点击使用单元格旁的一个共享编辑器，明确填写统计日期，区分零与未记录；点击精确数量与区间互斥。沿用网站 PATCH 接口和校验，仅提交对应字段组。失败保留编辑内容，取消不提交；离开时使用现有草稿保护。

服务商和仓库沿用部署资料中的实际资源关系，避免将服务商名称误当成主机、项目或仓库资源。数量与点击统计不自动获取，也不把编辑当天当成统计日期。

## 验证边界

使用本地自动化浏览器与隔离 Pages + D1 验收。没有推送 GitHub、部署 Cloudflare 或更新生产数据；线上登录后显示仍为上次发布版本。

## 2026-11-26：账号单选与网站分析资料

按用户确认，总表服务商和 GitHub 改为与电脑相同的单选交互，选择已有账号，显示图标与账号名。服务商只选择非 GitHub 账号，GitHub 只选择 GitHub 账号。此决定替代本文件及 ADR 0010 中这两列的资源展示与多账号展示规定。

单选只替换对应类别的直接网站账号关系，支持解除关联，不改变实际托管、仓库或资源所属账号；这些信息继续在部署资料管理。既有多个直接账号时显示明确提示，不自动选取或清除，用户选择后才在事务中替换。停用账号不可新选。

标题旁增加单站分析资料复制按钮，沿用多选 Markdown 导出；现有 GitHub 开发资料复制入口保留。AdSense 排序先按显示的开通标记分组，已开通且有账号名的记录再按账号名排序；未开通和未知不使用隐藏账号名参与排序。


同日补充：AdSense 列在账号名前显示网站累计美元收入，以两行排列保留紧凑列宽。复用网站接口的 `income_totals` 中 USD 合计，包含该网站已有的美元收入汇总口径，不跨币种换算；缺失显示“—”，已记录零显示 `$0.00`。保留接口现有的单站账号收入补充及同月显式网站记录优先规则，不把共用账号总额重复分配给各网站。排序在开通分组内优先按原始美元数值，同额再按账号名；未知和未开通继续显示叉。


同日展示修正：服务商与 GitHub 下拉选项和选中值统一显示图标及账号简称，不重复展示品牌文字，邮箱仅显示 `@` 前部分；完整账号保留在悬停提示中。电脑在总表、详情和批量设置中统一显示设备图标及简称，例如 `Mac Mini Luokun` 显示为图标＋`Luokun`，没有独立简称的型号与自定义名称保留原文。原始完整值继续用于保存与搜索；技术栈选项补充现有对应图标。


## 2026-11-26：内容优先的总表与共享选择浮层

用户确认优先保留内容可读性，窄窗口允许表格横向滚动。技术栈、服务商、GitHub、电脑、阶段默认只显示内容按钮；点击后在单例浮层选择，不再为每个单元格常驻输入框、背景、边框、箭头和清除按钮。这替代本文件此前的常驻下拉交互；现有账号单选、原始保存值及资源独立关系保持。

基础列宽依次为网站 240、技术栈 56、总页面 78、计算器 90、文章 78、日点击 88、服务商 144、GitHub 144、电脑 120、AdSense 112、阶段 80、操作 100 像素，共 1330 像素。宽屏剩余空间按网站 25%、服务商 30%、GitHub 30%、电脑 15% 分配；窄屏仅表格滚动，手机取消固定列，触屏操作列增至 144 像素。字体不缩小，身份图标为 16 像素、间距 4 像素；未设置账号与电脑显示 —。

浮层复用现有 Element Plus Popover 定位及传送能力，搜索完整值、显示简称，支持方向键、Enter、Esc、外部点击和焦点返回。选择后自动保存，成功关闭、刷新列表，失败保留原值及浮层供重试；保存时阻止重复操作。电脑和技术栈仍允许使用新名称。浮层与数量编辑互斥，不新增 API、数据库字段或经营阶段。详情及批量设置保持普通表单。

同日补充：服务商筛选按品牌分组，每组包含“全部账号”及已有账号，账号选项显示图标及简称，支持搜索完整邮箱。品牌与账号筛选互斥，分别沿用 `provider` 和 `provider_account` 地址参数；账号匹配包含直接关联及资源关联。刷新保留选择，筛选标签使用账号简称，清除可恢复全部网站。公共表单聚焦只保留一圈 1px 边界，高对比度模式使用系统轮廓。
