# 网站总表快捷编辑与 IP 列移除

## 状态

已接受，2026-11-21，用户明确要求。替代 ADR 0010、0011 中总表固定十二列的部分；其他数据与资源建模决策继续生效。当前仅本地开发，未发布。

## 决策

总表移除服务器 IP 列，保留十一列；IP 仍属于托管资源，可在部署资料查看。移除列定义、单元格、排序值和原复制处理，旧 `sort=ip` 地址按默认顺序展示，不保留隐藏排序。

阶段、电脑、技术栈直接下拉选择。电脑与技术栈允许输入新名称；自定义技术栈仍按 `platform=其他` 与 `platform_other` 保存，电脑仍属于网站。选项沿用现有电脑配置。

技术栈使用图标下拉，完整名称可在悬停及选项中查看；数量列使用紧凑宽度，宽屏多余空间分配给网站名称列，保留移动端至少 44px 操作目标。

总页面数、计算器数量、文章数量和日点击使用单元格旁的一个共享编辑器，明确填写统计日期，区分零与未记录；点击精确数量与区间互斥。沿用网站 PATCH 接口和校验，仅提交对应字段组。失败保留编辑内容，取消不提交；离开时使用现有草稿保护。

服务商和仓库沿用部署资料中的实际资源关系，避免将服务商名称误当成主机、项目或仓库资源。数量与点击统计不自动获取，也不把编辑当天当成统计日期。

## 验证边界

使用本地自动化浏览器与隔离 Pages + D1 验收。没有推送 GitHub、部署 Cloudflare 或更新生产数据；线上登录后显示仍为上次发布版本。
