# 网站总表与按用途管理部署资源

## 状态

已接受，2026-11-21。替代 ADR 0009 中经营场景驱动内容展示及待处理、批次优先导航的决策；批次历史和复盘能力保留。

旧字段映射和数量同步触发器的取舍已由 ADR 0011 替代；其余决策继续生效。

## 决策

网站总表为默认入口，固定十二列，批次、归属、技术栈、阶段及托管服务商为筛选维度。经营场景退出当前界面和内容判断，旧字段与历史复盘保留。总页面数、计算器数量、文章数量适用于所有技术栈；电脑表示网站的主要管理电脑。

继续复用账号、资源和网站关联模型，按托管、代码仓库、DNS/CDN、其他用途分别指定主要资源。服务商是托管资源的服务商品牌；Cloudflare DNS 不等于 Cloudflare 托管。GitHub 邮箱及默认加密 Token 属于凭据账号，网站通过仓库关联账号，复制时实时组合。

2026-11-22：按用户要求，总表“服务商”列改为显示网站关联的非 GitHub 服务账号，以服务商图标和账号简称呈现，邮箱账号只显示 @ 前的名称，悬停保留完整账号。包含直接关联及实际资源所属账号，同一账号只显示一次；无账号的托管资源保留品牌展示，筛选覆盖这两类来源。此展示决策替代上段仅显示托管品牌的规定，不将账号归属推断为实际托管位置，GitHub 仍由独立列展示。

GitHub 列同样以图标和关联账号简称呈现，悬停显示完整账号；直接关联的账号无需先创建仓库。已关联主要仓库的所属账号保留仓库跳转，尚未指定账号的仓库保留原仓库链接；多个账号分别展示，排序采用显示的账号名称。

Favicon 按域名持久缓存在现有 D1 中，不增加存储服务。列表只读缓存，后台及显式刷新获取图片，采用有界位图格式。

2026-11-23：按用户要求，在阶段前增加 AdSense 图标列，总表由十二列扩为十三列。开通状态继续读取网站的 `adsense_connected`，已开通显示勾，其余显示叉；悬停和无障碍名称区分未知与未开通，不根据账号关联推断。数量前的 Ads 复选框默认关闭，勾选仅展示明确已开通的网站，与现有条件取交集；状态进入网址，刷新保留、清除条件重置，隐藏行退出批量选择。顶部筛选下拉框缩窄为 120 像素，手机保持自适应换行。

## 取舍

保留旧字段并在边界映射，避免旧 API 与备份失效，代价是维护数量同步触发器。资源主体复用可减少重复录入，但旧混合用途需要人工核对。图标放 D1 减少部署配置，但限小图且普通备份不携带缓存。
