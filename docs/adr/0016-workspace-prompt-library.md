# 工作区提示词库与原文收集

## 状态

已接受，2026-11-26。

## 决策

提示词库是独立于网站的工作区资料，使用单层分类。标题行的第一个英文点号分隔分类和标题；正文按原文保存，不清理 Markdown 转义或反斜杠。粘贴识别只更新待确认表单，不产生写入。

同分类、同标题按英文大小写不敏感匹配，未分类也受唯一约束；新建分类与保存提示词在同一 D1 批次完成。删除分类先检查移到未分类的同名冲突，整体移动或整体失败。收藏不改变内容更新时间。

分类和提示词通过统一版本 1 JSON 备份导出、恢复；按分类名和标题匹配，预览显示覆盖数量，缺少提示词集合的旧备份不改写现有提示词。此扩展不改变 ADR 0011 的唯一工作区和单一备份入口。

首页与提示词库通过公共 `PromptEditorDialog` 组件收集和编辑，组件负责识别、分类、校验、保存、冲突预览及未保存保护。保存后只发出数据事件，不负责导航；首页保持原位并显示成功提示，提示词库自行更新列表和选择。弹窗样式随公共组件加载，直接打开首页也可完整使用。

## 取舍

首版只收集单条，不自动执行指令、不增加版本历史。正文可能包含用户原始转义，复制也保留。部署前在数据库副本演练 v1.31.0 增量迁移，再发布配套 Pages，已有库不重跑 schema.sql。
