# 移除外链来源与访问功能

## 状态

已接受（2026-11-08）

## 决策

移除台帐中的外链来源管理、网站候选、尝试记录和来源访问。移除相关页面、导航、API、AI 同步字段、导入导出字段、本地浏览器执行器和 D1 表。已有生产数据库通过 v1.21.0 迁移删除外链专属表和数据；网站、域名、收入、任务、资源及 AdSense 数据保持不变。

旧版 JSON 备份仍可导入；其中的外链字段会被忽略，不再恢复。历史迁移文件保留用于升级旧数据库，新的初始 schema 不再创建外链表。

## 原因

单纯访问第三方页面或附加目标域名参数不会创建公开链接，也无法验证 Google 收录。该流程没有达到外链建设目标，继续维护会增加界面、数据和运行成本，却不能产生预期结果。
