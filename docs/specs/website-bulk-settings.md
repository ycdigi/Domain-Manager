# 批量网站设置与同源问题复查

2026-11-22，批量设置与批次历史修正。发布遵照最终授权执行；发布记录见 `docs/bulk-settings-release.md`。

## 操作范围

| 项目 | 批量行为 |
|---|---|
| 服务商、GitHub 账号 | 从部署与账号选择已有账号，追加或解除直接关联；不创建占位资源 |
| 主机与 IP | 选择已有托管资源作为主要资源；不修改共用主机的 IP |
| 代码仓库、DNS/CDN、其他资源 | 按用途分别选择主要资源，或明确解除该用途全部资源关联 |
| 批次 | 追加已有批次；独立入口支持新建并加入、成员备注与移出；保留历次成员关系 |
| 电脑、GSC、AdSense | 设置已有值或明确清空；电脑可录入新名称 |
| 阶段、网站归属、技术栈、网站类型 | 统一设置；技术栈切换清理过时自定义名，选择其他可填写新名称 |
| 新站分类、GSC / AdSense 开通状态 | 独立设置；账号关联不推断开通状态 |
| 经营状态 | 总表批量停止或恢复经营 |

全部设置默认不修改。取消下拉选择恢复不修改；只有明确的清空／解除选项才删除现有关联。筛选后剔除不可见的选择，弹窗显示目标网站。单次最多 200 个网站。

## 根因与影响范围

1. 原批量接口只覆盖部分标量和账号关系，遗漏真实资源、批次及关联状态。统一校验后通过同一事务写入；失败整批回滚，未选网站、共享资源主体与关联备注保持原值。
2. 批次旧唯一约束将已移出历史限制为一条，重复移出冲突。v1.28 改为仅活动成员唯一；成员、批量加入、导入三个入口及备份恢复使用一致约束。恢复先写移出历史，避免活动成员冲突；拒绝重复历史 ID。
3. 大批量请求超过每条语句的参数预算。网站、批次加入和移出统一分组，所有写语句仍在同一事务。
4. 成员备注原先在重复加入时被忽略。未提供备注保留原值，明确提交备注修改，空字符串清空。
5. 新批次创建与导入原来分步写入，后续失败留下部分结果。新批次与成员、阶段，以及备份恢复与导入批次各自统一为事务；预览不创建批次，归档批次在预览阶段拒绝新增成员。
6. 批次详情筛选后仍保留不可见成员选择，可能误改其他网站；与总表、加入批次弹窗统一剔除筛选外选择。
7. 修改后部分读取缓存未失效，影响网站管理、批次复盘、账号统计与待处理。补齐相关变更入口的失效范围。
8. 单站资源主标记使用真假值判断，字符串可能错误取消主要资源。统一校验布尔值／0／1；单站与批量都拒绝停用账号、资源和不匹配用途。IP 创建与编辑同步校验。

9. 归档接口输出 ISO 时间，而恢复原先只接受日期，造成导出的归档批次无法导入。统一接受应用输出，验证归档批次备份预览与恢复。

域名后保留无文字的放大镜链接；阶段在行内选择；日点击行内输入、回车保存并显示档位和实际数字。

## 本地验证与边界

- 全量 Node / SQLite 回归：181 项通过，覆盖事务失败回滚、200 站参数预算、重复请求、批次多轮加入移出、历史恢复、导入预览与重复 ID。
- 构建、Functions 类型检查、监控类型检查、清理审计与差异检查通过。
- 浏览器：网站总表、批量设置、批次成员、网站管理、资源页面回归通过；批量设置含读取失败重试、草稿保留、清空与不修改、手机布局。
- 隔离本地 Pages + D1：账号、电脑、GSC、主机 IP、仓库、AdSense、阶段、批次实际写入，多轮成员历史与备份恢复通过；跨页面账号显示与新批次导入 UI 实际写入通过。
- v1.28 在隔离本地 D1 执行及重跑通过；旧成员 ID、备注、移出原因保留，再次加入产生新历史；外键无错，完整性为 ok。迁移回归比较新库／升级库结构，并验证序列保留。
- 未验证：生产业务数据写入交互；Safari 与 Firefox 手工交互；多客户端并发压力。线上只读验收与本地真实 API 写入验证分别记录。

## 统一发布要求

先备份当前 v1.27 库，在副本执行 `schema-migration-v1.28.0.sql` 并核对成员历史、外键和完整性，再发布配套应用；不得对已有库重新运行 schema.sql。迁移命令为 `db:migrate:v1.28.0`；生产备份、迁移与发布结果单独记入发布记录。
