# 人工审核外链来源与候选

## 状态

已接受

## 决策

外链流程分为来源、网站候选和人工尝试三个层次。新来源默认待审核、仅观察、未启用；只有已批准且启用的来源，候选才可以进入待处理。来源暂停、拒绝、失效或停用时，排队候选转为已暂停，重新批准后不自动恢复。

系统可以在浏览器本地根据已审核模板生成提交地址，但不会自动访问第三方网站、执行外部脚本、使用开放代理或提交表单。管理者手动处理后记录尝试结果和证据。请求执行状态保存为“已完成”“失败”或“需要人工”；提交待审核、被拒绝和来源失效作为同一条人工尝试的目录结果保存。只有人工已完成且带证据 URL 的记录才可以确认公开链接，候选状态入口不能直接写入这些结果。

AI 同步可以读取当前网站的来源和候选上下文，也可以更新已有候选的标题、描述、锚文本和备注。AI 不能新建或删除外链记录，不能改变候选状态、来源、目标或提交地址、处理日期和证据，也不能记录尝试或确认公开链接。

## 原因

旧版工具把“加载脚本成功”显示成外链成功，无法证明第三方页面公开展示了目标链接。将地址生成、请求结果和公开链接证据分开，才能避免把搜索地址、不可用页面或被拦截请求误记为外链。
