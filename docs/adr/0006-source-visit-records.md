# 来源访问记录队列

## 状态

已接受

## 决策

系统增加独立的“来源访问”流程：Mac Mini YC 上线后由常驻代理检查队列；按启用网站与来源生成网站 × 来源组合，每个组合实际访问一次。当前 101 个网站和 142 个来源一轮生成 14,342 个组合，使用普通浏览器逐个打开组合对应的来源 URL，并停留约 10–15 秒，按单队列每分钟或每五分钟执行，完成后停止或等待下一轮。来源模板有目标 URL 占位符时生成网站专属地址；没有占位符时仍保留本地组合进度，但不会宣称第三方页面产生了外链。访问不登录、不读取验证码、不提交表单、不检查 Google，也不把访问结果标记为外链成功。14,342 个组合的进度和断点状态保存在 Mac Mini 本地状态文件中，不写入 D1；D1 只保留一条最新运行汇总，以及每个来源一条最终检查结果，前者每次运行覆盖更新，后者按来源更新。

## 原因

管理者需要确认每个网站都轮到过，而不是只确认来源清单被访问过。组合进度必须在 Mac Mini 本地保留，才能支持 14,342 个组合的断点续跑；D1 只保存最新汇总和 142 个来源的最终筛选结果，避免把每个网站×来源组合和每次访问写入数据库。打开页面本身不能证明产生了外链，因此来源访问和公开链接仍然分开定义。

## 与既有决策的关系

本决策只补充来源访问记录，不改变人工审核外链候选、公开链接证据和外链提交结果的定义；它取代 ADR 0005 中“不会自动访问第三方网站”的范围限制。
