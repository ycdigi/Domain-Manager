# 人工审核外链来源与候选

## 状态

已接受

## 决策

外链流程分为来源、网站候选和人工尝试三个层次。新来源默认待审核、仅观察、未启用；只有已批准且启用的来源，候选才可以进入待处理。来源暂停、拒绝、失效或停用时，排队候选转为已暂停，重新批准后不自动恢复。

系统可以在浏览器本地根据已审核模板生成提交地址，但不会自动访问第三方网站、执行外部脚本、使用开放代理或提交表单。管理者手动处理后记录尝试结果和证据；只有已完成且带证据 URL 的记录才可以确认公开链接。

## 原因

旧版工具把“加载脚本成功”显示成外链成功，无法证明第三方页面公开展示了目标链接。将地址生成、请求结果和公开链接证据分开，才能避免把搜索地址、不可用页面或被拦截请求误记为外链。
