# Domain Docs

本项目使用单一领域结构：根目录 `GLOSSARY.md` 记录业务术语，`docs/adr/` 记录架构决策。

## 阅读规则

- 探索代码和编写规格前，阅读根目录 `GLOSSARY.md` 以及与任务相关的 `docs/adr/` 文档。
- 如果以后存在 `GLOSSARY-MAP.md`，按其中的映射阅读相关领域词汇表与决策。
- 缺少这些文档时继续工作，不预先创建空文件；术语和决策明确后再按领域建模流程记录。

## 术语与决策

- 事项、规格、分析和测试中的业务概念沿用词汇表，不用已明确避免的同义词替代。
- 网站归属关系、技术栈和网站类型是独立维度。
- 对与既有 ADR 冲突的提议明确指出冲突及理由，不静默覆盖已有决策。
- 词汇表只记录业务术语；功能规格、实现细节和临时讨论分别记录在合适的文档中。
