# 网站组合台帐与 AI 复查闭环

本次实现以已确认的产品方案和 ADR 0003、0004 为准。网站承担经营、任务、收入和投入记录；域名是可关联或未分配的独立资产。

## 使用流程

1. 新建网站时填写首个域名。首页按待评估、验证、增长、维护、暂停分组，组内箭头保存排序；停止经营网站单独查看，可恢复或显式删除。
2. 网站详情记录下一步及截止/完成状态、潜力、服务状态、内容统计、月收入和每周投入。任务与经营下一步分别保存。金额按月份、来源和币种存储，账号 AdSense 账目独立保留。
3. 管理者创建网站任务，可以手动或由 AI 更新既有任务。SEO 完成时只生成一个关联复查，默认等待 28 天；等待和前后窗口可在任务中调整。
4. 方便时手动提交 `AI-SYNC-PROMPT.md`。AI 先读取网站 ID、任务 ID、到期状态和快照，只回写已确认的信息。可在完成 SEO 时提交真实修改前点击基线；没有基线仍可完成 SEO，系统标记缺少基线。
5. 未到期的复查结论会被拒绝，其余有效更新继续处理。到期后使用指定的等长实际 GSC 点击窗口，保存点击量、AI 判断和依据；缺少修改后数据时保持待跟进，缺少可比基线时只能记录数据不足。

没有 GA4/GSC/AdSense 直连，也没有台帐主动调用 AI 或后台自动生成结论。复查由用户提交提示词触发。

## API 和数据

| 范围 | 当前入口 |
| --- | --- |
| 网站组合与经营资料 | `/api/websites`、`/api/websites/:id` |
| 域名资产、注册资料和归属 | `/api/domains`、`/api/domains/:id` |
| 网站任务、完成摘要和复查设置 | `/api/websites/:id/tasks`、`/api/websites/:id/tasks/:task_id` |
| 收入和每周投入历史 | `/api/websites/:id/income`、`/api/websites/:id/effort` |
| 操作记录和提示词版本 | `/api/websites/:id/operations`、`/api/websites/:id/ai-notes` |
| AI 只读上下文/回写 | `GET/POST /api/ai/sync`，使用 API_TOKEN |
| JSON / Excel 数据来源 | `/api/domains/export`、`/api/export/snapshot` |
| 导入及预览 | `/api/domains/import`，`dry_run=1` 仅预览 |

AI 回写必须使用稳定网站/任务 ID，不能创建网站或任务。未提供字段不覆盖已有值，复查任务不能绕过真实数据直接改成已完成。账号、资源、域名检查和非敏感导入导出功能继续保留。

新版 JSON 备份可恢复网站、域名、任务、快照、收入、投入、操作、账号、资源及提示词历史。网站和任务按稳定 ID 恢复，同名任务不会合并；账号/资源重新映射关联 ID。新版备份写入使用 D1 batch，失败整体回滚。备份不包含密码、Token、凭据密文或加密密钥。

历史网站类型只在台账和 AI 只读上下文中归一显示为“其他”，数据库及 JSON 备份保留原值。网站编辑和 AI 回写若回传归一后的“其他”，按未修改处理；选择其他合法类型才替换旧值。新建网站继续校验当前类型选项，旧版数组和新版快照导入则保留旧类型并正常恢复。

## 迁移和发布边界

`schema-migration-v1.15.0.sql` 在 v1.14.0 之后仅执行一次：每个旧域名迁为一个待评估网站及一个域名，网站 ID 延续旧域名 ID；Todo、操作、资源关联、归属和提示词历史随网站迁移。原逐站 AdSense USD 迁入网站通用收入，来源为 AdSense；账号月收入不变。旧域名经营字段和被替代表随后移除。

API 和数据库触发器都保护网站最后一个域名；显式删除网站可级联清理所属域名和历史数据。域名可在有其他域名保留的情况下解绑或转移。

生产发布前先备份 D1，再核对当前版本并执行缺失迁移，最后发布对应 Pages 代码。首次功能提交时没有执行生产迁移或部署；2026-11-07 的缺表故障处置及迁移记录如下。

2026-11-07 为修复远程 API 的 `no such table: websites`，已先导出并备份远程 `domains-db`，确认它仍含 v1.14 域名及关联数据后执行 v1.15.0 迁移。迁移后核对 101 个网站/101 个域名、21 条操作、14 条资源关联、4 条 AI 记录、2 个 AdSense 账号及收入记录；`PRAGMA foreign_key_check` 无异常。原列表的 0 张表显示与实际导出不一致，远程执行以数据库导出和迁移结果为准。

## 验收方式

- `node --test --test-concurrency=1 tests/*.test.mjs`：认证、网站/域名边界、资源、历史、AI 权限及字段、默认/自定义复查、迁移和备份恢复/回滚。
- `npm run lint:cleanup`：旧业务组件/API/表名引用、CSS 来源、共享 token 和队列字段。
- `npm run build`：TypeScript 和生产构建。
- `python3 tests/portfolio-ui.py`：Vite 5173 上的浏览器 fixture，覆盖阶段、停止经营、手机抽屉、未分配域名以及加载/空/失败/重试。
- `python3 tests/portfolio-local-ui.py`：仅允许本机 8788 隔离 Pages + D1，验证实际网站/任务/SEO/收入/投入/提示词写入、备份恢复、小数录入、组内排序、停止经营和下载；测试数据执行后删除。

本地 D1 迁移另以仓库原 v1.14 schema、种子网站/任务和 v1.15 迁移执行过验证，`foreign_key_check` 无异常。详细当次结果补录在根目录 `DASHBOARD-VERIFICATION.md`。
